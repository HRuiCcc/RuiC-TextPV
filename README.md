# RuiC-TextPV 文字PV — 歌词文字 PV 自动成片

填进歌词，自动把每一句切成几个镜头，给每个镜头挑排版、出现方式、停留动作、
消失方式、装饰、镜头运动和画面特效，然后在浏览器里直接导出 MP4。

默认打开的是「简易」工作台，直接播放一段示例歌词 PV。右侧「生成新版本」
会重选风格、气质与分镜；「导演编排」默认开启，把版式、字体角色、入场、背景、
装饰和转场按风格成套搭配。关闭后可使用完整零件库自由随机。切到「专业」仍可逐句
指定排版、出现、消失、停留、背景、镜头和文字加工；手动指定始终优先于导演编排。

RuiC-TextPV 是原创开发的浏览器歌词 PV 工具：界面、动效、中文分词与渲染引擎均为本项目独立实现。

---

## 一、怎么跑

### 直接打开（最省事）
双击仓库根目录的 `index.html`，或者：
```bash
open index.html
```
单文件、无需安装、无需联网（联网只是为了从 Google Fonts 取字体，
取不到就用本机字体兜底）。歌词与音乐只在浏览器里处理，不上传。

### 本地服务
```bash
python3 -m http.server 8123     # 然后打开 http://127.0.0.1:8123/index.html
```

### 从源码重新构建
```bash
python3 build.py                # 把 src/ + app/ + vendor/ 打成 index.html
```

## 三、动效设计层（本作重做的部分）

动效设计层按四条**物理直觉主线**组织演出，
在界面里带「新」字标记：

| 主线 | 新增演出 |
|---|---|
| **光学显影** | 感光显影、扫描显影、合焦、影先至、倒带、灼烧显字、霓虹渐亮、曝光过度、光扫显影 |
| **物理重量** | 落定、弹网、磁吸、表面张力、阶梯落定、翻飞入场、折纸展开、凿刻、踩拍炸开 |
| **声学响应** | 激振、逐字起浪、涟漪 · 微颤、潮汐、声压、心跳、沙沙、光流、焦点漂移、呼吸色 |
| **材质分解** | 微粒化、被风吹散、沉入景深、蒸发、灼烧、逐个吞噬、压成一线、翻面离场、光芒吞没、收拢成点、碎网消散 |

设计上的两个取舍：
- **声学响应**里的「声压」「心跳」「涟漪」是读取音频能量包络与拍点来驱动的，
  没有音乐时会自动降权，不会出现"对着空气抖"的尴尬。
- **材质分解**依赖字形碎块：引擎把每个字栅格化后按有笔画的网格切成碎块，
  所以爆散、微粒化、碎网消散这类效果贴的是**字形轮廓**，不是矩形。

## 四、用法要点

### 歌词写法
```
你总是盘旋在我脑海里面          一行 = 一句
夜色折成两半/我数着灯            / 手动指定切分点
*别急着*把它擦掉                 *强调*，会挑更冲的排版与演出
明天醒来还是这条街!              行尾 ! 加闪光与震动
歌词|小字                        竖线后面是注释小字
[01:23.45]歌词                   直接用 LRC 时间戳
# 这一行会被忽略                  注释
```

### 快捷键
| 键 | 作用 |
|---|---|
| `R` | 一键成片（风格 / 气质 / 动效 / 配色 / 分镜全换） |
| `空格` | 播放 / 暂停；打点模式下是打点 |
| `Esc` | 退出打点模式 |

### 三个入口
1. **一键成片** —— 整支片子重来。连按几次，总有一版能用。
2. **随机种子** —— 同一个种子排出来完全一样。满意就记下种子。
3. **重抽分镜** —— 保留风格与配色，只把分镜的排版与演出再抽一次。

### 行级控制（左栏「分镜表」）
每句一行：竖排编号 / 起始秒 / 歌词 / 重抽 / 锁定 / 七个下拉（排版 · 出现 · 消失 · 停留 · 背景 · 镜头 · 加工）。
下拉留空即"自动"，选定后就固定下来，不再受随机影响。

### 排版缩略图条
时间轴下方那条缩略图是**用真实引擎逐种排版渲染出来的**，
点一下就把当前这一句换成该排版，再点一次恢复自动。

### 导出
- **MP4**（H.264 / VP9 / AV1 自动协商，可带音乐）
- **连番 PNG**（ZIP）
- **透明 PNG**（ZIP，无背景，给后期合成用）
- **绿幕 / 黑幕**：画面只留白字与演出，给抠像或滤色叠加用
- **结构数据 JSON**：完整分镜数据，可用于交接或二次处理

画面比 16:9 / 9:16 / 4:3 / 3:4 / 1:1 / 4:5 / 21:9，720p ~ 4K，24 / 30 / 60fps。

### 「节奏」这一档
默认 **逐帧、60fps**，适合顺滑的逐字运动。需要手绘式定格感时，
可在「专业 → 动效」里切到二格或三格一拍。

一个镜头 = 排版 × 出现 × 停留 × 消失 × 加工 × 背景 × 镜头 ×（装饰 0~3 个）×（转场），
组合空间在千万级以上，再加上七档气质改变权重，所以同一个种子之外基本不会重复。

## 六、已知边界

- **MP4 导出**依赖 WebCodecs：Chrome / Edge 最新版最稳；Safari 16.4+ 与 Firefox 130+
  能跑，但能不能出 H.264 取决于系统。不支持时预览与连番 PNG 仍然可用。
- 中文分词用 `Intl.Segmenter('zh')`。极老旧浏览器会退化成按字符类别切块，效果略糙。
- 4K / 60fps 导出耗时较长，画面越复杂越明显；预览会主动降级（跳过后处理与转场）。

## 七、排版装置

让画面"像文字 PV"的其实不是排得齐，而是下面这些装置。它们都内置在引擎里：

| 装置 | 做法 | 在哪实现 |
|---|---|---|
| **横向拉伸** | 整块文字按 1.15~1.6 倍横向拉开，或压到 0.82 | `sx` 参数，几乎所有排版 |
| **字距开合** | 字距在 0.02~0.22 em 之间随机，密集与疏排交替出现 | `track` 参数 |
| **按字类给字号** | 汉字 1.0 / 片假名 0.88 / 拉丁 0.8 / 标点 0.42 / 平假名 0.5~0.66 | `Z.charScale` |
| **单字重点色** | 一行里只挑**一个**字换成强调色（优先落在假名或标点上） | `Z.accentPick` |
| **基线走法** | 直线 / 阶梯 / 波浪 / 拱形 四种基线 | `mode` 参数 |
| **整块偏移** | "居中"其实偏在中央附近（±5% 画面），不是死居中 | `ox` / `oy` |
| **微字散点** | 把整句小字副本撒在画面上下，随机旋转 ±20° | `Z.extrasText`（装饰件「微字散点」） |
| **背景字行** | 整屏滚动的小字行，隔行反向，随机抽掉几行 | `Z.bgRowsText`（装饰件「背景字行」） |
| **挖版** | 字底垫实色块，字挖成背景色 | 文字加工「挖版」/ `Z.knockout` |
| **复写副本** | 整行在旁边再写一遍，做成描边或压暗 | 文字加工「复写副本」/ `sideCopy` |
| **写字感** | 逐字极小的旋转、高低、大小差别 + 整块偶发倾斜 | `Z.letterFn`，动效面板可调 0~1 |

装饰件里有 9 个是**会动的**（刻度环、浮尘、波动条、环绕点、走马小字、记录点、边角刻度等），
并且所有装饰件都带进场：淡入 + 轻微位移 + 跟随镜头退场，不是静态贴图。
